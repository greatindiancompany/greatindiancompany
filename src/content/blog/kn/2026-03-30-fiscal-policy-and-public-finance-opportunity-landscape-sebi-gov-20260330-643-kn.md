ಸಾರ್ವಜನಿಕ ಲೆಕ್ಕಪತ್ರಗಳಲ್ಲಿನ ಅವಕಾಶ ಸರ್ಕಾರ ಖರ್ಚು ಮಾಡುತ್ತದೆ ಅಥವಾ ವರ್ಗಾಯಿಸುತ್ತದೆ ಎಂದು ಅಂದಾಜಿಸಿದ ರೂಪಾಯಿ, ಸಂಸ್ಥೆ ಅಥವಾ ರಾಜ್ಯ ಅದನ್ನು ನಿಜವಾಗಿ ಭೇಟಿಯಾಗಬಲ್ಲ ಸ್ಥಳದಲ್ಲಿ. ಅದು ಟೆಂಡರ್ ಅಲ್ಲ, ಮತ್ತು ಖಾಸಗಿ ಹೂಡಿಕೆ ಅನುಸರಿಸುತ್ತದೆ ಎಂಬ ವಾಗ್ದಾನವಲ್ಲ. ದೊಡ್ಡ ಅವಕಾಶಗಳನ್ನು ನೋಡಲು 2026-27ರ ಪ್ರಮುಖ ಲಕ್ಷಣಗಳ ಕಿರುಹೊತ್ತಿಗೆ (Key Features booklet) ಮತ್ತು ರಾಜಕೋಶ ಹೇಳಿಕೆ ಸಾಕು. ಅವನ್ನು ಯಾರು ಗೆಲ್ಲುತ್ತಾರೆ ಎಂದು ನೋಡಲು ಅವು ಸಾಕಾಗುವುದಿಲ್ಲ.

## ಕೇಂದ್ರ ವೆಚ್ಚದ ಒಂದು ರೂಪಾಯಿ ಈಗಾಗಲೇ ಏನು ಮಾಡುತ್ತದೆ

ಈ ಬಜೆಟ್‌ಗೆ ಕಿರುಹೊತ್ತಿಗೆಯ “ರೂಪಾಯಿ ಎಲ್ಲಿಗೆ ಹೋಗುತ್ತದೆ” ಚಿತ್ರ ವೆಚ್ಚವನ್ನು ವಿಭಜಿಸುತ್ತದೆ, ಮತ್ತು ಪಾಲುಗಳು 100ಕ್ಕೆ ಕೂಡುತ್ತವೆ:

| ರೂಪಾಯಿಯ ಪಾಲು | ಶೇಕಡಾ |
| --- | ---: |
| ತೆರಿಗೆಗಳಲ್ಲಿ ರಾಜ್ಯಗಳ ಪಾಲು | 22 |
| ಬಡ್ಡಿ ಪಾವತಿಗಳು | 20 |
| ಕೇಂದ್ರ ಕ್ಷೇತ್ರ ಯೋಜನೆಗಳು | 17 |
| ರಕ್ಷಣೆ | 11 |
| ಕೇಂದ್ರ ಪ್ರಾಯೋಜಿತ ಯೋಜನೆಗಳು | 8 |
| ಇತರ ವೆಚ್ಚ | 7 |
| ಹಣಕಾಸು ಆಯೋಗ ಮತ್ತು ಇತರ ವರ್ಗಾವಣೆಗಳು | 7 |
| ಪ್ರಮುಖ ಸಬ್ಸಿಡಿಗಳು | 6 |
| ನಾಗರಿಕ ನಿವೃತ್ತಿವೇತನ | 2 |

ಯೋಜನೆ ಅಥವಾ ರಕ್ಷಣಾ ಒಪ್ಪಂದವನ್ನು ತಲುಪುವ ಮೊದಲು ಶೇಕಡಾ ನಲವತ್ತೆರಡು ರಾಜ್ಯಗಳ ತೆರಿಗೆ ಪಾಲು ಜೊತೆಗೆ ಬಡ್ಡಿ. ಇನ್ನೊಂದು ಶೇಕಡಾ 8 ಸಬ್ಸಿಡಿಗಳು ಮತ್ತು ನಾಗರಿಕ ನಿವೃತ್ತಿವೇತನ. ವಿವೇಚನೆಯಂತೆ ಕಾಣುವ ಅವಕಾಶ ಉಳಿದದ್ದು: ಕೇಂದ್ರ ಕ್ಷೇತ್ರ ಯೋಜನೆಗಳು, ಕೇಂದ್ರ ಪ್ರಾಯೋಜಿತ ಯೋಜನೆಗಳು, ರಕ್ಷಣೆ ಮತ್ತು ಶೇಷ. “ಬಜೆಟ್”ಗೆ ಮಾರಾಟ ಮಾಡುವವರು ಆ ಶೇಷಕ್ಕೆ ಮಾರಾಟ ಮಾಡುತ್ತಿದ್ದಾರೆ, ಮತ್ತು ಅವರ ಸಚಿವಾಲಯ ನಿಜವಾಗಿ ನಿಯಂತ್ರಿಸುವ ಭಾಗಕ್ಕೆ ಮಾತ್ರ.

## ಪ್ರಮುಖ-ಅಂಶ ಪಟ್ಟಿ

ಅದೇ ಕಿರುಹೊತ್ತಿಗೆ ಪ್ರಮುಖ ಅಂಶಗಳ ವೆಚ್ಚವನ್ನು ₹ ಕೋಟಿಯಲ್ಲಿ ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ. ಇವು ಕಿರುಹೊತ್ತಿಗೆಯ ಶೀರ್ಷಿಕೆಗಳು, ಗ್ರೇಟ್ ಇಂಡಿಯನ್ ಕಂಪನಿ (Great Indian Company) ನಿರ್ಮಿಸಿದ ಶ್ರೇಣಿಯಲ್ಲ:

| ಅಂಶ | ₹ ಕೋಟಿ |
| --- | ---: |
| ಸಾರಿಗೆ | 5,98,520 |
| ರಕ್ಷಣೆ | 5,94,585 |
| ಗ್ರಾಮೀಣ ಅಭಿವೃದ್ಧಿ | 2,73,108 |
| ಗೃಹ ವ್ಯವಹಾರಗಳು | 2,55,234 |
| ಕೃಷಿ ಮತ್ತು ಸಂಬಂಧಿತ ಚಟುವಟಿಕೆಗಳು | 1,62,671 |
| ಶಿಕ್ಷಣ | 1,39,289 |
| ಇಂಧನ | 1,09,029 |
| ಆರೋಗ್ಯ | 1,04,599 |
| ನಗರ ಅಭಿವೃದ್ಧಿ | 85,522 |
| IT ಮತ್ತು ಟೆಲಿಕಾಂ | 74,560 |
| ವಾಣಿಜ್ಯ ಮತ್ತು ಕೈಗಾರಿಕೆ | 70,296 |

ಸಾರಿಗೆ ಮತ್ತು ರಕ್ಷಣೆ ₹6 ಲಕ್ಷ ಕೋಟಿಯ ಹತ್ತಿರದ ಎರಡು ಶೀರ್ಷಿಕೆಗಳು. ಗ್ರಾಮೀಣ ಅಭಿವೃದ್ಧಿ ಯಾವುದರ ಅರ್ಧಕ್ಕಿಂತ ಕಡಿಮೆ. ಆರೋಗ್ಯ ಮತ್ತು ಶಿಕ್ಷಣ ಈ ಪಟ್ಟಿಯಲ್ಲಿ ಇನ್ನೂ ಚಿಕ್ಕವು. “ಸಾರ್ವಜನಿಕ ಬಂಡವಾಳ ವೆಚ್ಚ”ವನ್ನು ಆಸ್ಪತ್ರೆಗಳು ಅಥವಾ ಶಾಲೆಗಳೊಂದಿಗೆ ಸಮೀಕರಿಸುವ ಸಂಸ್ಥೆ ಈ ಕೋಷ್ಟಕಕ್ಕಿಂತ ಬೇರೆ ದಾಖಲೆಯನ್ನು ಓದುತ್ತಿದೆ. ಸಾರಿಗೆ ಅಥವಾ ರಕ್ಷಣೆಯ ಎಷ್ಟು ಬಂಡವಾಳ, ಎಷ್ಟು ವೇತನ ಮತ್ತು ಎಷ್ಟು ವರ್ಗಾವಣೆ ಎಂದು ತೋರಿಸುವುದು ಅನುದಾನ ಬೇಡಿಕೆ, ಕಿರುಹೊತ್ತಿಗೆ ಸಾಲಲ್ಲ. ನಿವೃತ್ತಿವೇತನವನ್ನು, ನಿರ್ದಿಷ್ಟವಾಗಿ, ರಾಜಕೋಶ ಹೇಳಿಕೆಯಲ್ಲಿ ಬೇರೆಯಾಗಿ ಚರ್ಚಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಮೇಲಿನ ರಕ್ಷಣಾ ಸಾಲಿನೊಳಗೆ ಕುಳಿತಿದೆ ಎಂದು ಊಹಿಸಬಾರದು.

## ಖರೀದಿಗಳಲ್ಲ, ವರ್ಗಾವಣೆಗಳಾದ ಅವಕಾಶಗಳು

2026-27ರಲ್ಲಿ ರಾಜ್ಯಗಳಿಗೆ ತೆರಿಗೆ ಹಂಚಿಕೆ ₹15.26 ಲಕ್ಷ ಕೋಟಿ, 2025-26ರ ಪರಿಷ್ಕೃತ ಅಂದಾಜುಗಳಲ್ಲಿ ₹13.93 ಲಕ್ಷ ಕೋಟಿಯ ಎದುರು ಎಂದು ರಾಜಕೋಶ ಹೇಳಿಕೆ ಇಡುತ್ತದೆ. ಹದಿನಾರನೇ ಹಣಕಾಸು ಆಯೋಗದ (Sixteenth Finance Commission) ಪಾಲು ವಿಭಾಜ್ಯ ಪೂಲ್‌ನ (divisible pool) ಶೇಕಡಾ 41ರಲ್ಲೇ ಉಳಿಯುತ್ತದೆ. ಹಣಕಾಸು ಆಯೋಗದ ಅನುದಾನಗಳು ₹1.29 ಲಕ್ಷ ಕೋಟಿ: ಗ್ರಾಮೀಣ ಸ್ಥಳೀಯ ಸಂಸ್ಥೆಗಳು ₹0.56 ಲಕ್ಷ ಕೋಟಿ, ನಗರ ಸ್ಥಳೀಯ ಸಂಸ್ಥೆಗಳು ₹0.45 ಲಕ್ಷ ಕೋಟಿ, ಮತ್ತು ವಿಪತ್ತು ನಿರ್ವಹಣೆ ₹0.28 ಲಕ್ಷ ಕೋಟಿ. ಒಟ್ಟಾಗಿ, ಹಂಚಿಕೆ ಮತ್ತು ಈ ಅನುದಾನಗಳು ₹16.56 ಲಕ್ಷ ಕೋಟಿ.

ಕೇಂದ್ರ ಟೆಂಡರ್ ಮೂಲಕ ಹಾದುಹೋಗದ ಅತ್ಯಂತ ದೊಡ್ಡ ಅವಕಾಶ ಅದು. ಅದು ರಾಜ್ಯ ಖಜಾನೆಗಳು ಮತ್ತು ಸ್ಥಳೀಯ ಸಂಸ್ಥೆಗಳನ್ನು ತಲುಪುತ್ತದೆ. ಗುತ್ತಿಗೆದಾರ, ನಗರ ಹಣಕಾಸು ಅಧಿಕಾರಿ ಅಥವಾ ಸಹಕಾರಿ ಬ್ಯಾಂಕ್ ಅದನ್ನು ರಾಜ್ಯ ಬಜೆಟ್ ಅಥವಾ ಪುರಸಭೆ ಕಾಮಗಾರಿಯಲ್ಲಿ ಭೇಟಿಯಾಗುತ್ತದೆ, ಕೇಂದ್ರ ಭಾಷಣದಲ್ಲಿ ಅಲ್ಲ. ರಾಜ್ಯಗಳ ಸ್ವಂತ ಬಂಡವಾಳ ವೆಚ್ಚಕ್ಕೆ ಕೇಂದ್ರದ ಬಂಡವಾಳ ಸಾಲ ಇನ್ನೂ ₹2.0 ಲಕ್ಷ ಕೋಟಿ, ₹12.22 ಲಕ್ಷ ಕೋಟಿ ಕೇಂದ್ರ ಬಂಡವಾಳ ಸಾಲಿನೊಳಗೆ. ಆಸ್ತಿ, ನಿರ್ಮಾಣವಾದರೆ, ಯೋಜನೆಯ ಷರತ್ತುಗಳಡಿ ರಾಜ್ಯ ಆಯ್ಕೆ ಮಾಡುತ್ತದೆ.

## ಔಪಚಾರಿಕ ತೆರಿಗೆ ದಾಖಲೆಗಳು ವರ್ಣಿಸುವ ಮಾರುಕಟ್ಟೆ

GST ನೋಂದಣಿದಾರರು 2017ರಲ್ಲಿ 66.5 ಲಕ್ಷದಿಂದ ಮೇ 2026ರ ವೇಳೆಗೆ 1.65 ಕೋಟಿಗೆ ಏರಿದರು ಎಂದು [30 ಜೂನ್ 2026ರ ಪತ್ರ ಮಾಹಿತಿ ಕಚೇರಿ ಟಿಪ್ಪಣಿ (Press Information Bureau)](https://www.pib.gov.in/PressReleasePage.aspx?PRID=2279318&lang=1&reg=3) ಹೇಳುತ್ತದೆ. ಅದು ತೆರಿಗೆ ಗುರುತುಗಳ ಎಣಿಕೆ. ಸರಕುಪಟ್ಟಿ ವ್ಯವಸ್ಥೆಯೊಳಗೆ ಈಗಾಗಲೇ ಇರುವ ಸಂಸ್ಥೆಗಳ ತಲುಪಬಹುದಾದ ಸೆಟ್ ಅದು, ಇತರ ನೋಂದಾಯಿತ ಸಂಸ್ಥೆಗಳಿಗೆ ಮಾರಾಟ ಮಾಡಿ ಕ್ರೆಡಿಟ್ ಪಡೆಯಬಲ್ಲ ಸೆಟ್. ಸಾರಿಗೆ ಸಚಿವಾಲಯಕ್ಕೆ ಸರಬರಾಜು ಮಾಡಲು ಸಿದ್ಧ ಸಂಸ್ಥೆಗಳ ಎಣಿಕೆಯಲ್ಲ. 22 ಸೆಪ್ಟೆಂಬರ್ 2025ರ ನಂತರ ಜಾರಿಯಲ್ಲಿರುವ ದರ ರಚನೆ ಮುಖ್ಯವಾಗಿ ಶೇಕಡಾ 5 ಮತ್ತು 18, ಡಿಮೆರಿಟ್ ಪಟ್ಟಿಯ ಮೇಲೆ ಶೇಕಡಾ 40 ಎಂದೂ ಬ್ಯೂರೋ ಹೇಳುತ್ತದೆ. 2025ಕ್ಕೆ ಮೊದಲಿನ ದರ ಕಾರ್ಡ್‌ನ ಮೇಲೆ ಸಾರ್ವಜನಿಕ ಒಪ್ಪಂದಕ್ಕೆ ಬೆಲೆ ನಿಗದಿಪಡಿಸುವುದು ವಾಣಿಜ್ಯ ತಪ್ಪು, ರಾಜಕೋಶ ಒಳನೋಟವಲ್ಲ.

ಪ್ರಾಮಾಣಿಕ ಭೂದೃಶ್ಯ ಮೂರು ಬಾಗಿಲುಗಳು. ಒಂದು ಕೇಂದ್ರದ ಪ್ರಮುಖ ಶೀರ್ಷಿಕೆ, ವಿಶೇಷವಾಗಿ ಸಾರಿಗೆ ಮತ್ತು ರಕ್ಷಣೆ, ಅನುದಾನ ಬೇಡಿಕೆ ವೇತನವನ್ನು ಬಂಡವಾಳದಿಂದ ವಿಭಜಿಸಿದ ನಂತರವೇ ತೆರೆಯುತ್ತದೆ. ಒಂದು ಹಂಚಿಕೆ, ಹಣಕಾಸು ಆಯೋಗದ ಅನುದಾನಗಳು ಅಥವಾ ಬಂಡವಾಳ ಸಾಲದಿಂದ ಹಣಕಾಸು ಒದಗಿಸಿದ ರಾಜ್ಯ ಅಥವಾ ಸ್ಥಳೀಯ ಸಂಸ್ಥೆ. ಒಂದು ನೋಂದಾಯಿತ GST ಆಧಾರ, ಯಾರು ಔಪಚಾರಿಕ ಎಂದು ಹೇಳುತ್ತದೆ, ಯಾರಿಗೆ ಪಾವತಿಯಾಗುತ್ತದೆ ಎಂದಲ್ಲ. ರೂಪಾಯಿಯ ಶೇಕಡಾ 20ರಲ್ಲಿ ಬಡ್ಡಿ ಸರಬರಾಜುದಾರನಿಗೆ ಅವಕಾಶವಲ್ಲದ ಬಾಗಿಲು. ಸರಬರಾಜುದಾರನಿಗಿಂತ ಮೊದಲು ಪಾವತಿಯಾಗುವ ಹಕ್ಕು ಅದು.

ಗ್ರೇಟ್ ಇಂಡಿಯನ್ ಕಂಪನಿ ಆ ಬಾಗಿಲುಗಳಲ್ಲಿ ನಿಲ್ಲುತ್ತದೆ. ನೀಡಿಕೆ ಪತ್ರಗಳು ನಂತರದ ದಾಖಲೆ. ಇದರ ಸುತ್ತಲಿನ ಸಾರ್ವಜನಿಕ-ಹಣಕಾಸು ಟಿಪ್ಪಣಿಗಳು [greatindiancompany.com](https://greatindiancompany.com/) ನಲ್ಲಿವೆ.
