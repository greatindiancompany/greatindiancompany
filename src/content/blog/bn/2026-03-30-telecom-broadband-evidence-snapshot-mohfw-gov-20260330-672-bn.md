# ভারতের টেলিকম ও ব্রডব্যান্ড অঙ্কের একটি তারিখযুক্ত স্ন্যাপশট

নিচের প্রতিটি অঙ্ক সেই প্রকাশনার সঙ্গে বাঁধা যা সেটি ছাপিয়েছে। যেখানে দুটি সরকারি ধারা আলাদা, দুটি সারিই রাখা হয়েছে। এই পাতা সেগুলোর গড় করে না এবং তারিখের পর সেগুলো বাড়ায় না।

## 31 জুলাই 2026-এ গ্রাহক

উৎস: ভারতীয় দূরসংযোগ নিয়ন্ত্রক কর্তৃপক্ষের (Telecom Regulatory Authority of India, TRAI) প্রেস বিজ্ঞপ্তি নং 116/2026, 28 আগস্ট 2026।

| খাত | অঙ্ক |
| --- | --- |
| ব্রডব্যান্ড গ্রাহক | 1,094.48 million (জুন-শেষে 1,087.50 million; মাসিক বৃদ্ধি 0.64 percent) |
| যন্ত্র-থেকে-যন্ত্র সেলুলার সংযোগ বাদ দিয়ে ব্রডব্যান্ড | 1,005.72 million |
| স্থির তারযুক্ত ব্রডব্যান্ড | 48.14 million (মাসিক বৃদ্ধি 0.90 percent) |
| স্থির বেতার খণ্ড, 5G স্থির বেতার, Wi-Fi, ও উপগ্রহসহ | 18.84 million (মাসিক বৃদ্ধি 2.60 percent) |
| মোবাইল বেতার ব্রডব্যান্ড | 1,027.50 million (মাসিক বৃদ্ধি 0.59 percent) |
| 5G স্থির বেতার গ্রাহক | 13.21 million (শহুরে 6.56 million, গ্রামীণ 6.64 million) |
| অনুমোদনহীন ব্যান্ডের বেতার স্থির বেতার | 5.14 million (শহুরে 3.65 million, গ্রামীণ 1.49 million) |
| টেলিফোন গ্রাহক | 1,354.28 million |
| টেলি-ঘনত্ব | 94.68 percent (শহুরে 154.12 percent, গ্রামীণ 61.05 percent) |
| তারলাইন গ্রাহক | 48.01 million |
| তারলাইন টেলি-ঘনত্ব | 3.36 percent (শহুরে 8.28 percent, গ্রামীণ 0.57 percent) |
| শীর্ষ পাঁচ ব্রডব্যান্ড প্রদানকারীর অংশ | 98.59 percent |
| সর্বোচ্চ ভিজিটর-লোকেশন দিনে সক্রিয় বেতার গ্রাহক | 1,204.01 million (বেতার মোবাইল ভিত্তির প্রায় 93.48 percent) |
| জুলাইয়ে মোবাইল নম্বর পোর্টেবিলিটি অনুরোধ | 15.98 million |
| যন্ত্র-থেকে-যন্ত্র সেলুলার সংযোগ | 137.70 million |
| দিল্লি অনুমোদিত সেবা এলাকার টেলি-ঘনত্ব | 368.33 percent |
| বিহার অনুমোদিত সেবা এলাকার টেলি-ঘনত্ব | 64.19 percent |

জিও 535.12 million, এয়ারটেল 384.23 million, ভোডাফোন আইডিয়া 129.96 million, BSNL 27.28 million, এবং অ্যাট্রিয়া কনভারজেন্স টেকনোলজিস 2.47 million সেই নোটের শীর্ষ পাঁচ ব্রডব্যান্ড প্রদানকারী। নয়টি অনুমোদিত সেবা এলাকা সর্বভারতীয় টেলি-ঘনত্বের নিচে ছিল। TRAI শিরোনাম টেলি-ঘনত্বে যন্ত্র-থেকে-যন্ত্র (machine-to-machine) সংযোগ রাখে এবং জুলাই 2020-এর কারিগরি-দল প্রতিবেদনের জনসংখ্যা প্রক্ষেপণ ব্যবহার করে।
