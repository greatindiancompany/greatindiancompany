# భారత టెలికాం మరియు బ్రాడ్‌బ్యాండ్ సంఖ్యల తేదీల స్నాప్‌షాట్

కింద ప్రతి సంఖ్య దాన్ని ముద్రించిన ప్రచురణకు కట్టబడి ఉంది. రెండు అధికారిక శ్రేణులు విభిన్నంగా ఉన్న చోట, రెండు అడ్డు వరుసలు ఉంచబడతాయి. ఈ పేజీ వాటిని సగటు వేయదు మరియు వాటి తేదీ దాటి వాటిని పొడిగించదు.

## 31 జూలై 2026 నాటి చందాదారులు

మూలం: భారత టెలికాం నియంత్రణ ప్రాధికార సంస్థ (Telecom Regulatory Authority of India, TRAI) పత్రికా ప్రకటన సంఖ్య 116/2026 (Press Release No. 116/2026), 28 ఆగస్టు 2026.

| అంశం | సంఖ్య |
| --- | --- |
| బ్రాడ్‌బ్యాండ్ చందాదారులు | 1,094.48 మిలియన్లు (జూన్ చివర 1,087.50 మిలియన్లు; నెలవారీ వృద్ధి 0.64 శాతం) |
| యంత్రం-నుంచి-యంత్రానికి (machine-to-machine) సెల్యులార్ కనెక్షన్లను మినహాయించి బ్రాడ్‌బ్యాండ్ | 1,005.72 మిలియన్లు |
| స్థిర వైర్డు బ్రాడ్‌బ్యాండ్ | 48.14 మిలియన్లు (నెలవారీ వృద్ధి 0.90 శాతం) |
| స్థిర వైర్‌లెస్ విభాగం, 5G స్థిర వైర్‌లెస్, వై-ఫై (Wi-Fi), మరియు ఉపగ్రహంతో సహా | 18.84 మిలియన్లు (నెలవారీ వృద్ధి 2.60 శాతం) |
| మొబైల్ వైర్‌లెస్ బ్రాడ్‌బ్యాండ్ | 1,027.50 మిలియన్లు (నెలవారీ వృద్ధి 0.59 శాతం) |
| 5G స్థిర వైర్‌లెస్ చందాదారులు | 13.21 మిలియన్లు (పట్టణ 6.56 మిలియన్లు, గ్రామీణ 6.64 మిలియన్లు) |
| లైసెన్స్ లేని బ్యాండ్ రేడియో (unlicensed-band radio) స్థిర వైర్‌లెస్ | 5.14 మిలియన్లు (పట్టణ 3.65 మిలియన్లు, గ్రామీణ 1.49 మిలియన్లు) |
| టెలిఫోన్ చందాదారులు | 1,354.28 మిలియన్లు |
| టెలి-సాంద్రత (tele-density) | 94.68 శాతం (పట్టణ 154.12 శాతం, గ్రామీణ 61.05 శాతం) |
| వైర్లైన్ చందాదారులు | 48.01 మిలియన్లు |
| వైర్లైన్ టెలి-సాంద్రత | 3.36 శాతం (పట్టణ 8.28 శాతం, గ్రామీణ 0.57 శాతం) |
| మొదటి ఐదు బ్రాడ్‌బ్యాండ్ సేవాదాతల వాటా | 98.59 శాతం |
| పీక్ విజిటర్-లొకేషన్ రోజున క్రియాశీల వైర్‌లెస్ చందాదారులు | 1,204.01 మిలియన్లు (వైర్‌లెస్ మొబైల్ ఆధారంలో దాదాపు 93.48 శాతం) |
| జూలైలో మొబైల్ నంబర్ పోర్టబిలిటీ (mobile number portability) అభ్యర్థనలు | 15.98 మిలియన్లు |
| యంత్రం-నుంచి-యంత్రానికి సెల్యులార్ కనెక్షన్లు | 137.70 మిలియన్లు |
| ఢిల్లీ లైసెన్స్ పొందిన సేవా ప్రాంతం (licensed service area) టెలి-సాంద్రత | 368.33 శాతం |
| బిహార్ లైసెన్స్ పొందిన సేవా ప్రాంతం టెలి-సాంద్రత | 64.19 శాతం |

జియో (Jio) 535.12 మిలియన్లు, ఎయిర్‌టెల్ (Airtel) 384.23 మిలియన్లు, వోడాఫోన్ ఐడియా (Vodafone Idea) 129.96 మిలియన్లు, భారత్ సంచార్ నిగమ్ లిమిటెడ్ (Bharat Sanchar Nigam Limited, BSNL) 27.28 మిలియన్లు, మరియు ఆట్రియా కన్వర్జెన్స్ టెక్నాలజీస్ (Atria Convergence Technologies) 2.47 మిలియన్లు ఆ గమనికలో మొదటి ఐదు బ్రాడ్‌బ్యాండ్ సేవాదాతలు. తొమ్మిది లైసెన్స్ పొందిన సేవా ప్రాంతాలు అఖిల భారత టెలి-సాంద్రత కింద ఉన్నాయి. TRAI ముఖ్య టెలి-సాంద్రతలో యంత్రం-నుంచి-యంత్రానికి కనెక్షన్లను చేర్చుతుంది మరియు జూలై 2020 సాంకేతిక-బృంద నివేదిక నుంచి జనాభా అంచనాలను ఉపయోగిస్తుంది.
