# भारत के दूरसंचार और ब्रॉडबैंड आँकड़ों का दिनांकित चित्र

नीचे हर आँकड़ा उस प्रकाशन से बँधा है जिसने उसे छापा। जहाँ दो आधिकारिक शृंखलाएँ भिन्न हों, दोनों पंक्तियाँ रखी गई हैं। यह पृष्ठ उनका औसत नहीं निकालता और उन्हें उनकी तिथि से आगे नहीं बढ़ाता।

## 31 जुलाई 2026 के ग्राहक

स्रोत: भारतीय दूरसंचार विनियामक प्राधिकरण (Telecom Regulatory Authority of India, TRAI) की प्रेस विज्ञप्ति संख्या 116/2026 (Press Release No. 116/2026), 28 अगस्त 2026।

| मद | आँकड़ा |
| --- | --- |
| ब्रॉडबैंड ग्राहक | 1,094.48 मिलियन (जून के अंत में 1,087.50 मिलियन; मासिक वृद्धि 0.64 प्रतिशत) |
| मशीन-से-मशीन सेल्युलर कनेक्शन छोड़कर ब्रॉडबैंड | 1,005.72 मिलियन |
| फिक्स्ड वायर्ड ब्रॉडबैंड | 48.14 मिलियन (मासिक वृद्धि 0.90 प्रतिशत) |
| फिक्स्ड वायरलेस खंड, जिसमें 5G फिक्स्ड वायरलेस, Wi-Fi, और उपग्रह शामिल हैं | 18.84 मिलियन (मासिक वृद्धि 2.60 प्रतिशत) |
| मोबाइल वायरलेस ब्रॉडबैंड | 1,027.50 मिलियन (मासिक वृद्धि 0.59 प्रतिशत) |
| 5G फिक्स्ड वायरलेस ग्राहक | 13.21 मिलियन (शहरी 6.56 मिलियन, ग्रामीण 6.64 मिलियन) |
| बिना लाइसेंस वाले बैंड का रेडियो फिक्स्ड वायरलेस | 5.14 मिलियन (शहरी 3.65 मिलियन, ग्रामीण 1.49 मिलियन) |
| टेलीफोन ग्राहक | 1,354.28 मिलियन |
| टेली-घनत्व | 94.68 प्रतिशत (शहरी 154.12 प्रतिशत, ग्रामीण 61.05 प्रतिशत) |
| वायरलाइन ग्राहक | 48.01 मिलियन |
| वायरलाइन टेली-घनत्व | 3.36 प्रतिशत (शहरी 8.28 प्रतिशत, ग्रामीण 0.57 प्रतिशत) |
| शीर्ष पाँच ब्रॉडबैंड प्रदाताओं का हिस्सा | 98.59 प्रतिशत |
| चरम विज़िटर-लोकेशन वाले दिन सक्रिय वायरलेस ग्राहक | 1,204.01 मिलियन (वायरलेस मोबाइल आधार का लगभग 93.48 प्रतिशत) |
| जुलाई में मोबाइल नंबर पोर्टेबिलिटी अनुरोध | 15.98 मिलियन |
| मशीन-से-मशीन (machine-to-machine) सेल्युलर कनेक्शन | 137.70 मिलियन |
| दिल्ली लाइसेंस्ड सेवा क्षेत्र का टेली-घनत्व | 368.33 प्रतिशत |
| बिहार लाइसेंस्ड सेवा क्षेत्र का टेली-घनत्व | 64.19 प्रतिशत |

उस नोट में शीर्ष पाँच ब्रॉडबैंड प्रदाता हैं: Jio 535.12 मिलियन, Airtel 384.23 मिलियन, Vodafone Idea 129.96 मिलियन, भारत संचार निगम लिमिटेड (Bharat Sanchar Nigam Limited, BSNL) 27.28 मिलियन, और Atria Convergence Technologies 2.47 मिलियन। नौ लाइसेंस्ड सेवा क्षेत्र अखिल भारतीय टेली-घनत्व से नीचे थे। TRAI शीर्षक टेली-घनत्व में मशीन-से-मशीन कनेक्शन शामिल करता है और जुलाई 2020 की तकनीकी-समूह रिपोर्ट के जनसंख्या प्रक्षेपणों का उपयोग करता है।
