# Food Processing In India: State Pattern Means A List, Not A Ranking

## Do not rank states from this page

This brief does not rank states by output, plants, or employment. It does not assign a crop to a state as if that assignment were a census. A state pattern in food processing is whichever official list names the district, the cluster, or the pack house.

## The district list is ODOP

PMFME uses One District One Product. The product chosen for a district is published through the PMFME portal, not through a national league table. Preference for the district product shows up in how the scheme is written. The common-processing facility on the ministry's infrastructure page is for ODOP produce. A state team that wants a pattern should pull the current district list, then see which of those products has a common line, a farm-gate grading shed, or a cold store that other users can hire.

New micro units and existing ones are not described identically in the scheme material. Check the current rule for whether ODOP is required for the category you are in. This page does not freeze that rule.

## The cluster list is a PMKSY component

Infrastructure for Agro-processing Clusters remains on the list of PMKSY components the ministry says it is implementing. Mega Food Parks do not. The PMKSY page says Mega Food Parks were discontinued in the 15th Finance Commission cycle, with committed liability still provided for. A state slide that still leads with a new Mega Food Park is describing an older pattern.

Clusters are demand-driven project proposals, not a quota this brief can map onto a blank state. The pattern is the approved project the ministry records, plus the produce catchment the proposal itself names.

## The export-plant list is APEDA's

Recognized horticulture pack houses are listed by APEDA with state and product scope. That list is the state pattern for export handling of fresh produce: which plant, in which state, for which fruits or vegetables, for which validity window. Grapes, pomegranate, mango, okra, and chilli appear as product scopes on that public list. This brief does not convert those crop names into a state ranking, and it does not treat a snapshot of the list as complete.

APEDA's about page also lists where the authority itself sits. Regional offices named there include Ahmedabad, Bengaluru, Bhopal, Bihar, Chandigarh, Chennai, Guwahati, Jammu, Kochi, Kolkata, Ladakh, Mumbai, Raipur, Srinagar, Telangana, Tripura, Varanasi, and Visakhapatnam, with the head office in New Delhi. That is an administrative footprint. It is not a map of where processing output is highest.

## How to use the three lists together

For a state note, put three columns on one page: the district ODOP product, any agro-processing cluster the ministry has actually recorded, and any APEDA-recognized pack house with its product scope. Leave the cells blank when the list is blank. A blank cell is a better description than a borrowed tonnage figure.
