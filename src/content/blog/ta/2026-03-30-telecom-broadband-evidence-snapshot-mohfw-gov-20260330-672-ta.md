# இந்தியாவின் தொலைத்தொடர்பு மற்றும் அகலப்பட்டை எண்களின் தேதியிட்ட படம்

கீழே உள்ள ஒவ்வொரு எண்ணும் அதை அச்சிட்ட வெளியீட்டுடன் பிணைக்கப்பட்டுள்ளது. இரண்டு அதிகாரப்பூர்வ தொடர்கள் வேறுபடும் இடத்தில் இரண்டு வரிசைகளும் வைக்கப்பட்டுள்ளன. இந்தப் பக்கம் அவற்றைச் சராசரி இடவில்லை. அவற்றின் தேதிக்கு அப்பால் நீட்டவும் இல்லை.

## 31 ஜூலை 2026 சந்தாதாரர்கள்

மூலம்: இந்தியத் தொலைத்தொடர்பு ஒழுங்குமுறை ஆணையம் (Telecom Regulatory Authority of India, TRAI) செய்திக் குறிப்பு எண் 116/2026 (Press Release No. 116/2026), 28 ஆகஸ்ட் 2026.

| --- | --- |
| அகலப்பட்டை சந்தாதாரர்கள் | 1,094.48 மில்லியன் (ஜூன் இறுதியில் 1,087.50 மில்லியன்; மாதாந்திர வளர்ச்சி 0.64 சதவீதம்) |

| நிலையான கம்பிவழி அகலப்பட்டை | 48.14 மில்லியன் (மாதாந்திர வளர்ச்சி 0.90 சதவீதம்) |

| உரிமமில்லா அலைக்கற்றை வானொலி நிலையான வயர்லெஸ் | 5.14 மில்லியன் (நகர்ப்புறம் 3.65 மில்லியன், ஊரகம் 1.49 மில்லியன்) |
| தொலைபேசி சந்தாதாரர்கள் | 1,354.28 மில்லியன் |

| கம்பிவழி சந்தாதாரர்கள் | 48.01 மில்லியன் |
| கம்பிவழி தொலைபேசி அடர்த்தி | 3.36 சதவீதம் (நகர்ப்புறம் 8.28 சதவீதம், ஊரகம் 0.57 சதவீதம்) |

| ஜூலையில் கைபேசி எண் பெயர்வுக் கோரிக்கைகள் | 15.98 மில்லியன் |
| இயந்திரத்திலிருந்து இயந்திரம் செல்லுலார் இணைப்புகள் | 137.70 மில்லியன் |
| தில்லி உரிமம் பெற்ற சேவைப் பகுதி தொலைபேசி அடர்த்தி | 368.33 சதவீதம் |
| பீகார் உரிமம் பெற்ற சேவைப் பகுதி தொலைபேசி அடர்த்தி | 64.19 சதவீதம் |

அந்தக் குறிப்பில் Jio 535.12 மில்லியன், Airtel 384.23 மில்லியன், Vodafone Idea 129.96 மில்லியன், BSNL 27.28 மில்லியன், Atria Convergence Technologies 2.47 மில்லியன் ஆகியவை முதல் ஐந்து அகலப்பட்டை வழங்குநர்கள். ஒன்பது உரிமம் பெற்ற சேவைப் பகுதிகள் அகில இந்திய தொலைபேசி அடர்த்திக்குக் கீழே இருந்தன. TRAI இயந்திரத்திலிருந்து இயந்திரம் இணைப்புகளை தலைப்பு தொலைபேசி அடர்த்தியில் சேர்க்கிறது. ஜூலை 2020 தொழில்நுட்பக் குழு அறிக்கையின் மக்கள்தொகை முன்கணிப்புகளைப் பயன்படுத்துகிறது.
