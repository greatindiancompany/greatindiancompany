જાહેર ખાતાંમાં તક એ રૂપિયો છે જે સરકારે ખર્ચવાનો અથવા હસ્તાંતર કરવાનો અંદાજ મૂક્યો છે, એવી જગ્યાએ જ્યાં પેઢી અથવા રાજ્ય ખરેખર તેને મળી શકે. તે ટેન્ડર નથી, અને તે વચન નથી કે ખાનગી રોકાણ પાછળ આવશે. 2026-27ની મુખ્ય લક્ષણોની પુસ્તિકા (Key Features booklet) અને રાજકોષીય નિવેદન મોટા દ્વાર જોવા માટે પૂરતાં છે. તે કોણ જીતશે તે જોવા માટે પૂરતાં નથી.

## કેન્દ્રીય ખર્ચનો એક રૂપિયો પહેલેથી શું કરે છે

આ બજેટ માટે પુસ્તિકાનું “રૂપિયો ક્યાં જાય છે” ચિત્ર ખર્ચ વિભાજે છે, અને હિસ્સા 100 સુધી ઉમેરાય છે:

| રૂપિયાનો હિસ્સો | ટકા |
| --- | ---: |
| રાજ્યોનો કર હિસ્સો | 22 |
| વ્યાજ ચૂકવણી | 20 |
| કેન્દ્રીય ક્ષેત્ર યોજનાઓ | 17 |
| સંરક્ષણ | 11 |
| કેન્દ્ર પ્રાયોજિત યોજનાઓ | 8 |
| અન્ય ખર્ચ | 7 |
| નાણાં આયોગ અને અન્ય હસ્તાંતર | 7 |
| મુખ્ય સબસિડી | 6 |
| નાગરિક પેન્શન | 2 |

બેતાલીસ ટકા રાજ્યોનો કર હિસ્સો વત્તા વ્યાજ છે, યોજના અથવા સંરક્ષણ કરાર સુધી પહોંચાય તે પહેલાં. બીજા 8 ટકા સબસિડી અને નાગરિક પેન્શન છે. વિવેકાધીન દેખાતું દ્વાર જે બાકી રહે છે તે છે: કેન્દ્રીય ક્ષેત્ર યોજનાઓ, કેન્દ્ર પ્રાયોજિત યોજનાઓ, સંરક્ષણ, અને બાકી. “બજેટ”માં વેચનાર તે બાકીમાં વેચે છે, અને ફક્ત તે ભાગમાં જે તેમનું મંત્રાલય ખરેખર નિયંત્રે છે.

## મુખ્ય-વસ્તુ યાદી

એ જ પુસ્તિકા મુખ્ય વસ્તુઓનો ખર્ચ યાદી આપે છે, ₹ કરોડમાં. આ પુસ્તિકાના મથાળાં છે, ગ્રેટ ઇન્ડિયન કંપની (Great Indian Company)એ બનાવેલો ક્રમ નહીં:

| વસ્તુ | ₹ કરોડ |
| --- | ---: |
| પરિવહન | 5,98,520 |
| સંરક્ષણ | 5,94,585 |
| ગ્રામ વિકાસ | 2,73,108 |
| ગૃહ વ્યવહાર | 2,55,234 |
| કૃષિ અને સંલગ્ન પ્રવૃત્તિઓ | 1,62,671 |
| શિક્ષણ | 1,39,289 |
| ઊર્જા | 1,09,029 |
| આરોગ્ય | 1,04,599 |
| શહેરી વિકાસ | 85,522 |
| આઇટી અને ટેલિકોમ | 74,560 |
| વાણિજ્ય અને ઉદ્યોગ | 70,296 |
| સામાજિક કલ્યાણ | 62,362 |
| વૈજ્ઞાનિક વિભાગો | 55,756 |

પરિવહન અને સંરક્ષણ ₹6 લાખ કરોડની નજીકના બે શીર્ષક છે. ગ્રામ વિકાસ બેમાંથી કોઈના અડધા કરતાં ઓછો છે. આરોગ્ય અને શિક્ષણ આ યાદી પર હજી નાનાં છે. જે પેઢી “જાહેર મૂડી ખર્ચ”ને હોસ્પિટલ અથવા શાળા સાથે સરખાવે છે તે આ સારણીથી અલગ દસ્તાવેજ વાંચે છે. અનુદાનની માગ, પુસ્તિકાની રેખા નહીં, બતાવે છે કે પરિવહન અથવા સંરક્ષણનો કેટલો ભાગ મૂડી છે, કેટલો પગાર છે, અને કેટલો હસ્તાંતર છે. પેન્શન, ખાસ કરીને, રાજકોષીય નિવેદનમાં અલગ ચર્ચાય છે અને ઉપરની સંરક્ષણ રેખાની અંદર બેઠી છે એવું ધારવું ન જોઈએ.

## જે દ્વાર ખરીદી નથી, હસ્તાંતર છે

રાજકોષીય નિવેદન 2026-27માં રાજ્યોને કર હસ્તાંતર ₹15.26 લાખ કરોડ મૂકે છે, 2025-26ના સુધારેલા અંદાજમાં ₹13.93 લાખ કરોડ સામે. સોળમા નાણાં આયોગ (Sixteenth Finance Commission)નો હિસ્સો વિભાજ્ય પૂલના 41 ટકા જ રહે છે. નાણાં આયોગ અનુદાન ₹1.29 લાખ કરોડ છે: ગ્રામીણ સ્થાનિક સંસ્થાઓ ₹0.56 લાખ કરોડ, શહેરી સ્થાનિક સંસ્થાઓ ₹0.45 લાખ કરોડ, અને આપત્તિ વ્યવસ્થાપન ₹0.28 લાખ કરોડ. મળીને, હસ્તાંતર અને આ અનુદાન ₹16.56 લાખ કરોડ છે.

તે સૌથી મોટું દ્વાર છે જે કેન્દ્રીય ટેન્ડરમાંથી પસાર થતું નથી. તે રાજ્ય તિજોરીઓ અને સ્થાનિક સંસ્થાઓ સુધી પહોંચે છે. ઠેકેદાર, શહેર નાણાં અધિકારી, અથવા સહકારી બેંક તેને રાજ્ય બજેટ અથવા નગરપાલિકા કામમાં મળે છે, કેન્દ્રીય ભાષણમાં નહીં. રાજ્યોના પોતાના મૂડી ખર્ચ માટે કેન્દ્રનું મૂડી ઋણ વધુ ₹2.0 લાખ કરોડ છે, ₹12.22 લાખ કરોડની કેન્દ્રીય મૂડી રેખાની અંદર. મિલકત, જો બને, યોજનાની શરતો હેઠળ રાજ્ય પસંદ કરે છે.

## ઔપચારિક કર રેકોર્ડ વર્ણવે છે તે બજાર

[30 જૂન 2026ની પ્રેસ ઇન્ફોર્મેશન બ્યુરો (Press Information Bureau) નોંધ](https://www.pib.gov.in/PressReleasePage.aspx?PRID=2279318&lang=1&reg=3) કહે છે કે જીએસટી નોંધણીકર્તા 2017માં 66.5 લાખથી મે 2026 સુધીમાં 1.65 કરોડ થયા. તે કર ઓળખની ગણતરી છે. તે ઇન્વૉઇસ પ્રણાલીની અંદર પહેલેથી રહેલી પેઢીઓનો સરનામાંયોગ્ય સમૂહ છે, એ સમૂહ જે અન્ય નોંધાયેલી પેઢીઓને વેચી શકે અને જમા માગી શકે. તે પરિવહન મંત્રાલયને પુરવઠો આપવા તૈયાર પેઢીઓની ગણતરી નથી. બ્યુરો એ પણ કહે છે કે 22 સપ્ટેમ્બર 2025 પછી અમલમાં રહેલી દર રચના મુખ્યત્વે 5 અને 18 ટકા છે, ડિમેરિટ યાદી પર 40 ટકા સાથે. 2025 પહેલાંના દર કાર્ડ પર જાહેર કરારની કિંમત નક્કી કરવી વ્યાપારી ભૂલ છે, રાજકોષીય સૂઝ નહીં.

પ્રામાણિક ભૂમિ ત્રણ દ્વાર છે. એક કેન્દ્રીય મુખ્ય શીર્ષક છે, ખાસ કરીને પરિવહન અને સંરક્ષણ, જે અનુદાનની માગ પગારને મૂડીથી વિભાજે પછી જ ખુલે છે. એક રાજ્ય અથવા સ્થાનિક સંસ્થા છે જેને હસ્તાંતર, નાણાં આયોગ અનુદાન, અથવા મૂડી ઋણથી ધિરાણ મળે છે. એક નોંધાયેલો જીએસટી આધાર છે, જે કહે છે કે કોણ ઔપચારિક છે, કોને ચૂકવણી થશે તે નહીં. રૂપિયાના 20 ટકા વ્યાજ એ દ્વાર છે જે પુરવઠાકાર માટે તક નથી. તે દાવો છે જે પુરવઠાકાર પહેલાં ચૂકવાય છે.

ગ્રેટ ઇન્ડિયન કંપની તે દ્વાર પર અટકે છે. એનાયત પત્ર પછીનો દસ્તાવેજ છે. આની આસપાસની જાહેર-નાણાં નોંધો [greatindiancompany.com](https://greatindiancompany.com/) પર છે.
