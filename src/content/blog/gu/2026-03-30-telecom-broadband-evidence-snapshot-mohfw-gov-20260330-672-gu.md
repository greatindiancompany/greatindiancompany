# ભારતના ટેલિકોમ અને બ્રોડબેન્ડ આંકડાઓનો તારીખવાળો સ્નેપશૉટ

નીચેનો દરેક આંકડો તે પ્રકાશન સાથે બંધાયેલો છે જેણે તે છાપ્યો. જ્યાં બે સત્તાવાર શ્રેણીઓ અલગ પડે, બંને હરોળ રાખવામાં આવી છે. આ પાનું તેમની સરેરાશ કાઢતું નથી અને તેમની તારીખ પછી તેમને લંબાવતું નથી.

## 31 જુલાઈ 2026ના ગ્રાહકો

સ્રોત: ભારતીય ટેલિકોમ નિયામક પ્રાધિકરણ (Telecom Regulatory Authority of India, TRAI) પ્રેસ વિજ્ઞપ્તિ નં. 116/2026, 28 ઑગસ્ટ 2026.

| --- | --- |

| મશીન-ટુ-મશીન સેલ્યુલર જોડાણો સિવાયનું બ્રોડબેન્ડ | 1,005.72 મિલિયન |
| ફિક્સ્ડ વાયર્ડ બ્રોડબેન્ડ | 48.14 મિલિયન (માસિક વૃદ્ધિ 0.90 ટકા) |
| ફિક્સ્ડ વાયરલેસ ખંડ, 5G ફિક્સ્ડ વાયરલેસ, Wi-Fi અને ઉપગ્રહ સહિત | 18.84 મિલિયન (માસિક વૃદ્ધિ 2.60 ટકા) |

| અનલાઇસન્સ્ડ-બેન્ડ રેડિયો ફિક્સ્ડ વાયરલેસ | 5.14 મિલિયન (શહેરી 3.65 મિલિયન, ગ્રામીણ 1.49 મિલિયન) |
| ટેલિફોન ગ્રાહકો | 1,354.28 મિલિયન |

| વાયરલાઇન ગ્રાહકો | 48.01 મિલિયન |
| વાયરલાઇન ટેલી-ડેન્સિટી | 3.36 ટકા (શહેરી 8.28 ટકા, ગ્રામીણ 0.57 ટકા) |
| ટોચના પાંચ બ્રોડબેન્ડ પ્રદાતાઓનો હિસ્સો | 98.59 ટકા |
| મહત્તમ વિઝિટર-લોકેશન દિવસે સક્રિય વાયરલેસ ગ્રાહકો | 1,204.01 મિલિયન (વાયરલેસ મોબાઇલ આધારના આશરે 93.48 ટકા) |
| જુલાઈમાં મોબાઇલ નંબર પોર્ટેબિલિટી (mobile number portability) વિનંતીઓ | 15.98 મિલિયન |
| મશીન-ટુ-મશીન (machine-to-machine) સેલ્યુલર જોડાણો | 137.70 મિલિયન |
| દિલ્હી લાઇસન્સ્ડ સર્વિસ એરિયા (licensed service area) ટેલી-ડેન્સિટી | 368.33 ટકા |
| બિહાર લાઇસન્સ્ડ સર્વિસ એરિયા ટેલી-ડેન્સિટી | 64.19 ટકા |

રિલાયન્સ જિયો (Reliance Jio) 535.12 મિલિયન, ભારતી એરટેલ (Bharti Airtel) 384.23 મિલિયન, વોડાફોન આઇડિયા (Vodafone Idea) 129.96 મિલિયન, ભારત સંચાર નિગમ લિમિટેડ (Bharat Sanchar Nigam Limited, BSNL) 27.28 મિલિયન, અને એટ્રિયા કન્વર્જન્સ ટેક્નોલોજિસ (Atria Convergence Technologies) 2.47 મિલિયન તે નોંધમાં ટોચના પાંચ બ્રોડબેન્ડ પ્રદાતાઓ છે. નવ લાઇસન્સ્ડ સર્વિસ એરિયા સમગ્ર ભારતની ટેલી-ડેન્સિટીથી નીચે હતા. TRAI મુખ્ય ટેલી-ડેન્સિટીમાં મશીન-ટુ-મશીન જોડાણો ગણે છે અને જુલાઈ 2020ના તકનીકી-જૂથ અહેવાલની વસ્તી અંદાજો વાપરે છે.
